# CHROMIQ — Logo Guidelines

## 1. The logo
- **Idea**: a browser window whose traffic lights are three gold four-point sparkles, over a split compare view. It says "browser-first design workbench" without drawing a tool.
- **Versions**: horizontal (primary) · stacked · symbol · wordmark · small-size symbol.
- **Wordmark**: custom lowercase "chromiq", drawn as paths (no font needed). The i is dotted with a Star Gold sparkle.
- **Construction**: the sparkles and both panes are real cut-outs in the indigo window. The colour files fill the sparkles with Star Gold, and the panes show the background. One-colour versions keep every shape automatically.

## 2. Files
| Use | File |
|---|---|
| Screens, light backgrounds | `chromiq-horizontal.svg`, `chromiq-stacked.svg`, `chromiq-symbol.svg`, `chromiq-wordmark.svg` |
| Dark backgrounds (`night` #0F0D14) | `*-on-dark.svg`: violet keyline around the window, light wordmark |
| One colour (print, stamps, stickers) | `one-colour/*-black.svg`, `*-white.svg`, `*-mono-4b0082.svg` |
| Below 32 px | `chromiq-symbol-small.svg`: one bigger sparkle, thicker frame |
| App icon | `web/chromiq-app-icon.svg` (window on white) |
| Website icons | `web/favicon.ico`, `favicon.svg`, `apple-touch-icon.png`, `icon-192/512.png`, `maskable-512.png`, `site.webmanifest`, `head-snippet.html` |
| Raster | `png/` (symbol 1024, horizontal 2400, stacked 1200, horizontal on dark) |

## 3. Clear space
Keep a clear zone the height of one traffic-light sparkle on every side of the logo. The zone scales with the logo.

## 4. Minimum size
| Version | Screen | Print |
|---|---|---|
| Horizontal | 140 px wide | 35 mm wide |
| Symbol | 32 px (below that, use the small-size symbol down to 16 px) | 10 mm |

## 5. Colour
| Name | HEX | RGB | CMYK (approx.) | Pantone (approx.) |
|---|---|---|---|---|
| Nanashi Indigo (window, wordmark) | #4B0082 | 75 0 130 | 42 100 0 49 | 2617 C or 2685 C |
| Star Gold (sparkles, i-dot) | #FFC857 | 255 200 87 | 0 22 66 0 | 1225 C |
| Night (dark background) | #0F0D14 | 15 13 20 | 25 35 0 92 | Black 6 C |
| Keyline violet (dark backgrounds only) | #A283E6 | 162 131 230 | — | — |
| Wordmark on dark | #EEECF3 | 238 236 243 | — | — |

**Approved backgrounds**: full colour on white or `bg` #FBFAFD · on-dark version on `night` · white one-colour version on Nanashi Indigo · black on white.

The i-dot sparkle stays Star Gold on every background, which was a deliberate choice. On white it has only about 1.5:1 contrast, so it reads as an accent, not as part of the name: the letters carry the name, and the dot is decoration. Never use gold for text.

## 6. Typography around the logo
Headings in Sora 600 and UI text in Plus Jakarta Sans, both under the SIL Open Font License from Google Fonts. The wordmark is custom artwork, so never retype it in a font.

## 7. Don'ts
Don't stretch, rotate or recolour the logo. Don't change the number of sparkles or their order. Don't fill the panes. Don't add shadows, glows or gradients. Don't put the full-colour logo on the product accent, on gold or on busy photos. Don't rebuild the wordmark by typing it.

## 8. Notes
- The Nanashi design system reserves indigo for the studio signature. Using Nanashi Indigo and Star Gold for this product's logo was a deliberate choice. CHROMIQ's UI can keep its violet accent.
- Browser-window icons are common, for example AWS Certificate Manager's window with a star. Search for "CHROMIQ" as a name too. Do a trademark search, plus a reverse image search, before launch.
